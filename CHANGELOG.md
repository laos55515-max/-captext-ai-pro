# CapText AI Pro — аудит и модернизация (v1.1, 2026-11-09)

Ветка: `arena/336f3610-captext-ai-pro`. Все правки внесены в рабочую копию репозитория —
файлы в проекте уже содержат исправленный код. Этот документ — отчёт аудита + инструкция.

## TL;DR (почему пропадали первые 1–2 слова)

Тихую атаку первого слова (fade-in) Silero/энергетический VAD **не видит** и находит
речь на 0.3–1.5 с позже. Дальше сработали три защиты от галлюцинаций —
и все три удаляли реальный текст:

1. `align_text()` **физически отрезал** начало аудио по `first_onset − 0.08 с`
   (допуск на атаку всего 80 мс!) → вокалиста с fade-in первые слова
   просто не попадали в выравнивание.
2. `filter_by_vad()` **удалял** слова, не пересекающиеся с VAD-интервалами
   (допуск всего 0.25 с) → тихая атака первого слова выбрасывалась.
3. `drop_intro_hallucinations()` удалял слова, закончившиеся до `onset − 0.35 с`.

Дополнительно «жёсткая привязка» сдвигала **всю песню** к VAD-онсету при любом
размере сдвига — при позднем VAD это давало заметное запаздывание субтитров.

### 2. Анти-галлюцинации (тишина → выдуманный текст)

`condition_on_previous_text=False` + `no_speech_threshold=0.6` выставлены в
`stable-ts`, `faster-whisper` (и в легаси `asr_align.py`). Существующие фильтры
(`is_hallucination`, `drop_repeat_hallucinations`, `drop_intro_hallucinations`)
сохранены и покрыты тестами — «Песня «Музыка»», «Субтитры сделал…» и т.п.
по-прежнему вырезаются. Новое: предупреждение в report/statusbar при **абсолютной
тишине** (VAD пуст) вместо молчаливой генерации мусора.

### 3. Ручная задержка субтитров (Padding) — НОВАЯ ФУНКЦИЯ

Вкладка «📝 Текст» → группа **«⏱ Тайминг субтитров (Padding)»**: слайдер ±2.00 с
(шаг 0.05 с, PageStep 0.20 с), живая подпись `+0.00 с`, кнопка сброса ⟲.

- Не разрушает тайминги слов: хранится в `Project.subtitle_offset` (э —5…+5 с).
- Применяется мгновенно: предпросмотр в плеере, подсветка строки в таблице,
  клик-перемотка по таблице, рендер видео и экспорт SRT (таймстампы клампятся в ≥ 0).
- Сохраняется/загружается вместе с `.ctp`-проектом (миграция не требуется — есть дефолт).

### 4. UI/UX модернизация

- **Прогресс-бар**: выше (22–24 px), `%p%` + этап («…Распознавание чистого вокала…»,
  «Кадр N/M…» от экспортёра), при 100% — «готово». ObjectName `StageProgress`.
- **Плавные анимации**: fade-in панелей при старте каскадом (левая → правая),
  проявление таблицы после обработки (450 мс). Реализовано через
  `QGraphicsOpacityEffect` + `QPropertyAnimation` (`app/ui/widgets.py::fade_in`),
  эффект снимается по завершении — ноль цены на кадрах после анимации.
- **Тёмная тема** (`app/ui/theme.py`): контрастнее вторичный текст (`MUTED #9AA7BC`),
  рамки `LINE #273043`, градиентные панели (12–14 px скругления), мягкое выделение
  строк (`#12374A` вместо неон-заливки), стилизованные чекбоксы/меню/фокус/сплиттер/
  скроллбары, hover для первичной кнопки.
- **Inter теперь реально грузится**: `main.py` регистрирует `assets/fonts/*.ttf`
  через `QFontDatabase` при старте (+ `setFont`), `captext_ai_pro.spec` добавляет
  `assets/fonts` в бандл (`[spec] шрифты Inter в бандле`). Раньше QSS просил Inter,
  но семейство не было зарегистрировано — молча откатывался на системный шрифт.
- Таблица: подсветка текущей строки учитывает `subtitle_offset` (двусторонняя
  синхронизация остаётся консистентной).

### 5. Перфоманс и устойчивость

- One-pole IIR в `_bandpass()` переведён с Python-цикла на `scipy.signal.lfilter`
  (scipy приходит с librosa; есть безопасный fallback на цикл).
- VAD предупреждает об абсолютной тишине (`VAD не обнаружил голос…`), слова
  отсутствуют, приложение не падает; битые/пустые/оборванные файлы → понятное
  `AudioDecodeError` (см. тесты E).
- `.gitignore`: добавлен `.venv/`.

faster-whisper 1.0.3 · demucs 4.0.1 · torch/torchaudio 2.2.2.

## Как обновить локальный проект и пересобрать (macOS)

```bash
cd -captext-ai-pro
git fetch origin && git checkout arena/336f3610-captext-ai-pro && git pull
# зависимости — те же, что и раньше; верхних ограничений нет
./build_macos.sh
```

Сборка менять не нужно: `captext_ai_pro.spec` сам положит `assets/fonts` в бандл.
После запуска проверить:

1. Открыть тихий трек с fade-in → «🚀 Создать субтитры»: первое слово **на месте**.
2. Вкладка «Текст» → слайдер «⏱ Тайминг субтитров (Padding)» — субтитры сдвигаются
   мгновенно; кнопка ⟲ возвращает 0.00 с.
3. «Advanced» → «Диагностика»: `Старт вокала: … с · VAD: … (пре-ролл 1.0 с)`.
